Pre-packaged AI agent bundles ("AI office manager for pest control") at flat pricing would be compelling.
- **Speed to Market**: 3-4 weeks using Claude API + existing vertical software webhooks
- **LTD Fit**: Moderate — agents require ongoing inference costs, but a capped LTD tier is feasible
- **Content Strategy**: "AI for pest control business," "automated follow-up HVAC quotes," "AI scheduling lawn care"
