  - Bluebeam / PlanSwift: legacy incumbents (expensive, desktop-first)
- **White Space**: Trade-specific takeoff tools (electrical-only material lists, plumbing fixture scheduling), takeoff tools integrated directly with material supplier pricing (Home Depot/Grainger API), or mobile-first photo-to-estimate for small residential remodelers
- **Speed to Market**: 4-6 weeks MVP for a narrow scope (e.g., photo-to-estimate for kitchen remodels only)
- **LTD Fit**: High — contractors hate per-seat SaaS; would strongly prefer a one-time deal for estimating tools at $199-499

  - https://www.upstartsmedia.com/p/toothy-ai-lassie-raises-35m (Lassie $35M Series A, a16z, Jun 2026; 700+ dental practices, saves 30-100 hrs/month)

- **Market Timing**: Growing — Archy and Lassie are Series A/C but the market is vast and legacy incumbents are weak
- **Example Products**:
  - Archy: https://archy.com (full practice management + AI agents, 45 states)
  - Lassie: AI admin automation layer for dental (700+ practices, $250M valuation)
  - Dentrix / Eaglesoft: legacy incumbents being disrupted
- **White Space**: The Lassie/Archy pattern applied to optometry chains, dermatology practices, or physical therapy clinics — same legacy software problem, same admin burden, less crowded
- **Speed to Market**: 6-8 weeks for a narrow AI admin layer (e.g., insurance claims automation only for one practice type)
- **LTD Fit**: Low for practices — healthcare ACV is high enough for MRR, but a dental admin automation tool at $99-199/mo is viable
