## Problem Statement

Property management companies handling 100+ units employ in-house maintenance techs whose hours and expenses are tracked on paper or spreadsheets, then manually re-entered into Buildium/AppFolio at month-end. The pain is real but narrow: the workflow exists in every PM company of a certain size, but only property management-specific software (not generic time trackers) can close the loop from tech's mobile clock-in → property assignment → billable hours → Buildium expense line item.

**Core gap**: No mobile app lets maintenance techs clock in by property, attach a photo of the work, log materials/expenses, and sync to Buildium as a maintenance charge — in one workflow.

## Target Customer

- Property management companies managing 50-500 units with 2-10 in-house maintenance techs
- Currently on Buildium, AppFolio, or Yardi Breeze
- Currently using paper timesheets or generic Google Sheets for tech tracking

## Competitor Landscape

| Tool | Gap |
|------|-----|
| Buildium | No native tech time tracking; expense entry is manual desktop-only |
| AppFolio | Maintenance requests exist; no tech time tracking or billable hours |
| Connecteam | Generic time tracking; no Buildium/PM software integration |
| TSheets/QuickBooks Time | No property assignment; no PM software sync |
| Maintenance Connection | Enterprise-priced CMMS; not for small-to-mid PM companies |

**Unoccupied combination**: Mobile clock-in → property tag → photo → Buildium expense sync at $29-49/mo.

## Key Risks

1. Buildium could add this natively (Buildium has an open API but rarely builds integrations proactively)
2. Small addressable market — mid-size PM companies (50-500 units) with in-house techs is a narrow ICP
3. Depends on third-party API availability; Buildium API changes could break integration
